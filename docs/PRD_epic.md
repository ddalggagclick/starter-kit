## 1. 에픽 — 8개

### E1. 카카오톡으로 시작하는 상속 절차 안내

**목표**  카카오에서 개인 상황을 최소 입력으로 선택하고 웹으로 자연스럽게 이어가도록 한다.

**흐름**  K-01(카카오 초기 3문항) 3문항 → K-02(카카오 절차 추천) 최대 5개 추천 → K-03(카카오 위험 질문 3종) 위험 3종 즉시 경고 → K-04(카카오 절차 안내) 핵심 상세 → 10분·1회 Handoff.

**담당·구현**  카카오 스킬 JSON은 B2 어댑터로 정규화; 추천은 B1의 단일 ChecklistService; Handoff는 서버 메모리 원자 소비.

**제외·주의**  MCP/AI 생성으로 카카오 질문을 늘리지 않음. 법적 효과 미판정, 플랫폼 5초 응답 실패 시 대체 안내.

**완료 조건**  초기 답변이 웹 W-02에서 재질문 없이 복원되고, 만료/재사용을 거부하며 3종 위험 안내가 구분된다.

**순서·릴리스**  ④ 카카오 챗봇 / MVP

---

### E2. 웹 체크리스트와 공식 절차 상세

**목표**  웹에서 자신의 상황에 맞춘 체크리스트를 탐색하고 실제 공식 절차를 안전하게 확인한다.

**흐름**  웹 첫 화면 → 관계·사망일·안심상속 신청 3문항 → 맞춤 체크리스트(최대 5개) 또는 전체 8개 절차 → 절차 상세 → 답변 수정·재확인 → 상속 관계·상속세 기본 안내. 피드백은 Mock 버튼·모달만 만든다.

**담당·구현**  B1 체크리스트는 결정론적 규칙, W-04(웹 절차 상세) 안내는 FE가 RAG 공식 소스를 기준으로 선작성·대조 후 개발.

**제외·주의**  우선 추천은 법적 의무가 아님. '안내 확인'은 신청 완료가 아님. 상세 접힘 M-10 일부 보류, 피드백 전송 기능은 MVP 이후.

**완료 조건**  최대 5개 추천, 전체 8개 탐색, 수정 후 영향 표시와 위험 경고, 검수 출처를 가진 상세 안내가 동작한다.

**순서·릴리스**  ③ Mock 프론트엔드 / MVP

---

### E3. 웹 AI 질의응답 및 출처 기반 안전 안내

**목표**  사용자가 공식 근거가 있는 일반 상속 질문을 하고 검증된 답변·출처를 볼 수 있게 한다.

**흐름**  AI 질문 입력(W-07) → Gemini 분류 → RAG/MCP/부칙 OPEN API → Gemini 답변 1회 → 출처 검증 → 상태/SSE·자동 타이핑.

**담당·구현**  200 코드포인트, 직전 동일 채팅 사용자 질문 0~3개; Gemini 기본. Gemini 429 사용량 제한 상태(S9) 처리·자동 Ollama 전환 금지.

**제외·주의**  출처 없으면 근거 부족 시 본문 비공개(S7: 판단 유보). 미검증 토큰 공개 없음. 비회원 AI 하루 10회·공급자 제한 별도.

**완료 조건**  질문별 출처 실제 URL 확인, S6(기술 오류)/S7/S9 구분, 자동 타이핑·취소·비회원 제한이 검증된다.

**순서·릴리스**  ③ Mock → ⑤ 검증 이전 V1 / MVP

---

### E4. 브라우저 기록·독립 동의·개인정보 제어

**목표**  개인정보를 사용자가 직접 선택·관리하며 기록을 보존/삭제하도록 한다.

**흐름**  체크리스트/대화 별도 기기 저장 동의 → IndexedDB → 계정별 분리·삭제·철회; 회원 별도 서버 체크리스트 저장 동의.

**담당·구현**  Zustand는 메모리, Dexie는 동의 후 로컬 기록. 서버는 로그인+별도 동의의 체크리스트만; AI 대화 원문 DB 비저장.

**제외·주의**  자동 병합 금지. 백업/복원/충돌 고도화는 MVP+4일 이후; 저장 실패는 메모리 계속 이용 가능.

**완료 조건**  미동의 저장 0건, 계정 교차 노출 없음, 동의·삭제/철회 분리, 서버 저장은 로그인+별도 동의만.

**순서·릴리스**  후속 MVP 구현 / MVP

---

### E5. JWT 회원가입·로그인 및 계정 상태

**목표**  비회원 접근을 유지하면서 안전한 계정 가입·인증·회복·탈퇴를 제공한다.

**흐름**  회원가입/이메일 확인 → 로그인·JWT → Refresh·로그아웃 → 비밀번호 재설정 → 계정 탈퇴. 비회원 헤더·AI 제한 진입.

**담당·구현**  FastAPI 자체 Auth + Argon2id, Access 15분 메모리, Refresh 7일 HttpOnly 회전형, Supabase Session Pooler 5432.

**제외·주의**  로그인 실패 5회/15분. 브라우저 타사 쿠키 검증; 메일사업자·암호 세부 수치/재설정 토큰은 월요일 확정.

**완료 조건**  회원가입부터 로그아웃·재설정·탈퇴까지 정상/만료/도용·회전 재사용 시나리오 검증.

**순서·릴리스**  ③ Mock → 후속 MVP 구현 / MVP

### E6. 공식자료 RAG·법령 근거의 신뢰성 확보

**목표**  공식 안내자료·법령이 최신 출처와 시행 시점에 맞게 답변으로 전달되도록 한다.
