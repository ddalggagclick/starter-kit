# backend/ 담당 에이전트 지침

- 담당/책임: **[B/C/통합] 상속 전용 FastAPI; 하위 디렉터리별 담당이 다름**

- 사용자가 명시적으로 승인하지 않은 테이블 생성/ERD 변경/새 패키지 도입/배포 설정 변경을 하지 않습니다.
