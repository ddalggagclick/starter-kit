# 일반 법률 안내 화면

`guide-page.tsx`는 상속 관계와 상속세에 관한 일반 안내를 표시합니다. 콘텐츠는 `shared/content/general-info.ts`에서 가져오며, `cited-text.tsx`가 문장 안의 출처 표기를 렌더링합니다. 화면 하단에는 공식 기관 링크와 오류 제보 버튼이 있습니다.

이 화면은 개인별 상속인 판정이나 상속세 계산을 수행하지 않습니다. 제보 버튼은 `features/reports/feedback-mock-dialog.tsx`의 Mock 모달을 엽니다. Backend 법령 조회는 이 정적 안내 화면과 별도로 `backend/src/inheritance/law/`가 담당합니다.

일반 안내 화면 구현과 통합 검증을 완료했습니다.
