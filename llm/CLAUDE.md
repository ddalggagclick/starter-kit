# llm/ 담당 에이전트 지침

**루트 `AGENTS.md` / `CLAUDE.md`를 반드시 먼저 읽고 준수하세요.** 이 문서는 해당 디렉터리에서 추가 적용하는 범위 제한입니다.

- 담당/책임: **[C] 독립 LLM/모델 Provider**
- 수정 허용: **`llm/**`**. 하위 폴더 소유자 및 공유 계약 승인 규칙을 따릅니다.
- 다른 영역(`backend/**`, `frontend/**`, `rag/**`, 루트 `.github/**`, 승인되지 않은 공통 계약·문서)의 파일은 **작성·수정·삭제·포맷·리네임 금지**. 연결 문제는 소유자에게 인터페이스 변경 제안을 전달합니다.
- Backend와 RAG를 import하지 않는다. 공급자 객체는 ModelPort 뒤로 숨긴다.
- **모델 공급자(3-2-4, 2026-10-21 변경):** Gemini 기본, 제한(429)·장애·시간 초과 시 `LLM_FAILOVER_PROVIDERS` 순서(기본 `groq`, 선택 `groq,ollama`)로 **다음 공급자에 자동 전환**한다. 요청마다 공급자별 최대 1회만 시도하고 같은 공급자를 반복 재시도하지 않으며 API 키를 임의로 교체하지 않는다. 목록 밖 공급자로는 전환하지 않는다. 모두 실패하면 오류(429이면 S9)를 그대로 올린다.
- **Ollama:** 로컬 전용 선택 항목이다(Render 불가). LLM은 `LLM_OLLAMA_*`를, RAG는 별도 이름(`RAG_` 접두 권장)을 쓰며 변수·키를 공유하지 않는다. `llm/`은 RAG를 import하지 않는다.
- **키 분리:** `GEMINI_API_KEY`, `GROQ_API_KEY`는 서로 다른 값이며 로그·오류·status·테스트 출력에 남기지 않는다.
- **공유 계약:** `contracts/*`는 호환을 유지한다(`ModelSelection`의 `auto_fallback`은 계속 거부, 전환 정책은 별도 `FailoverPolicy`). 변경이 필요하면 소유자와 API 담당 승인을 받는다.
- 기능 구현 전 공개 DTO/Port 및 실패·취소·무근거 케이스를 확인합니다. 모의 테스트와 외부 실연동 결과를 혼동하지 않습니다.
- 사용자가 명시적으로 승인하지 않은 테이블 생성/ERD 변경/새 패키지 도입/배포 설정 변경을 하지 않습니다.
